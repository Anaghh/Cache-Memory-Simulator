Memory traffic

Counts are memory transactions and transferred bytes. Dirty resident lines stay pending at the end; Reset discards them. A dirty eviction writes a whole block, while write-through and write-around send one byte.

L1, L2, L3: follow the miss

Unit 3, slides 19 and 42–49. Read accesses probe levels in order and fill the missed upper levels.

Hierarchy settings

Illustrative byte capacities, not real CPU sizes.

How timing works

Each probe adds its configured latency. An L2 hit costs t₁ + t₂; a RAM access costs the sum of all cache probe times + RAM time.

AMAT = t₁ + m₁(t₂ + m₂(t₃ + m₃ × RAM))

Omit disabled levels. m₂ and m₃ are local miss rates among requests reaching that level. Measured AMAT = total demand-read latency ÷ CPU accesses. This follows the additive worked example in slide 44. The lab is serial, read-only, and non-inclusive/non-exclusive: lower-level eviction does not invalidate upper levels, and no inclusion or exclusivity guarantee is enforced. No prefetching, bandwidth contention, or coherence timing.

A cache for translations

Unit 3, slides 50–61. A TLB miss triggers a page-table lookup; it does not automatically mean a page fault.

TLB settings

Omitted pages fault. Frames must be unique integers 0–255. One address space, no ASIDs.

Translation lookaside buffer

Translation history

Physical address = frame × page size + unchanged offset. A missing resident page is reported as a fault and is not automatically loaded from disk. OS paging, permissions, and multilevel page-table walks are outside this model.

Branch target buffer

A BTB caches branch targets. This teaching extension pairs a 4-entry direct-mapped BTB with a 2-bit direction counter.

4-byte aligned addresses. T = taken, N = not taken. On a BTB miss predict PC + 4.
UNIT 3 · SLIDE 16 / UNIT 4 · MULTICORE

Two-core coherence

See shared copies and invalidation on a write. Different bytes in the same 8-byte block can cause false sharing.

Core 0 or 1. R/W accesses. Writes default to 1.

Simplified serialized write-through, write-invalidate model with unbounded private caches. Labels describe clean copy ownership; this is not a full MESI/MOESI protocol. Cache coherence governs copies of one location; consistency governs ordering across locations.
